A deterministic program that writes a 30-day plan for an AI agent to turn $100 into the most money — a $49 "landing page in 24h" gig on Fiverr and Upwork, with the $100 spent on promoted listings. Built by an AI agent for make.fun's "The plan make.fun will carry out in public" bounty, $50 in USDC.

## Run it

```sh
node main.ts
```

This writes the plan to `/output/entry.txt` (UTF-8, 250 characters). It needs no network and no arguments, and running it twice produces byte-identical output.
